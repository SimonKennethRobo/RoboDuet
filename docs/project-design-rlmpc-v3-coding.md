# Response-Consistent Locomotion Policy — 需求文档

**目标**：训练出一个 **response-consistent** 的四足 locomotion policy，使闭环响应 `locomotion command → base SE(3)` 可被一个低阶模型准确描述，供下游 policy-aware SE(3) MPC 使用。

**范围**：论文 Contribution 1（策略训练）+ Contribution 2 所需的数据导出接口。**不含**闭环辨识、feasibility envelope、MPC 求解器。

---

## 关于这份文档怎么用

本文档给出的是**需求与不变量**，不是实现方案。文件放在哪、buffer 叫什么名字、在哪个回调里更新、用什么数据结构，全部由你根据实际代码结构决定。

区分标准：

- **必须遵守**的是需求中标注为「不变量」的条目、以及数学定义和验收标准。这些是设计决策，改动会破坏方法本身。
- **可以自主决定**的是一切代码组织方式、命名、模块划分、张量布局。

如果你认为某条不变量在这个代码库里不合理或有更好的实现路径，**先提出并等待确认**，不要直接绕过。

数值参数表标注为「起点值」的，意思是先用它跑通，随后由标定流程替换。

## R1 — 命令空间裁剪

### 需求

把 MoB 的高维行为空间收缩到 MPC 会实际使用的 5 个决策通道，其余固定。

**MPC 决策通道（5 维）**：前向速度、侧向速度、偏航角速度、body height、body pitch。

**固定通道**：步态类型锁定为 trot；body roll 恒为 0；footswing height、stance width、duty 固定（可加小幅随机化用于鲁棒性）。

**半自由通道**：gait frequency 在窄范围（约 2.5–3.5 Hz）随机训练，部署时固定，但需要作为后续残差模型的条件输入被记录。

### 不变量

- 被冻结的通道**保留其在命令向量中的位置**，只是不采样。删除索引会改变观测维度，污染与原版的对比实验。
- 自适应课程只在 5 个决策通道上运行；gait frequency 走独立均匀采样，不进课程。

### 设计依据

- 不同步态的 gait-phase residual 结构完全不同，混训会让残差模型无法收敛。
- body roll 的可命令幅值（±10° 量级）与 trot 固有 roll 振荡（±2–4°）同量级，信噪比不支持可靠辨识。v1 冻结，留作消融。
- body height 与 body pitch 必须保留为决策变量，因为 MPC 需要用 body lean / height adjustment 辅助 manipulation。

### 验收

固定命令下 rollout，确认冻结通道数值恒定；观测维度与原版一致。

## R2 — 参考响应模型

### 需求

为 5 个决策通道各引入一条**参考响应轨迹**。策略被训练去跟踪这条轨迹，而不是直接跟踪命令。这条参考轨迹后续将**直接成为 MPC 的 nominal dynamics**，因此它是"规定的"而非"辨识的"。

模型形式：**二阶临界阻尼 + 速率饱和**，各通道独立。

```
ẍ = ωₙ²(u − ξ) − 2ζωₙξ̇ ,   ξ̇ ∈ [−ṙₘₐₓ, +ṙₘₐₓ] ,   ζ = 1.0
```

起点值（**必须由 R8 标定流程替换**）：

| 通道        | ωₙ (rad/s) | 速率上限    |
| ----------- | ------------ | ----------- |
| 前向速度    | 8.0          | 1.2 m/s²   |
| 侧向速度    | 6.0          | 0.8 m/s²   |
| 偏航角速度  | 8.0          | 3.0 rad/s² |
| body height | 7.0          | 0.25 m/s    |
| body pitch  | 5.0          | 0.8 rad/s   |

### 不变量

- **命令重采样时不得重置参考状态**。命令跳变时参考状态从当前值平滑演化过去，这才是二阶系统的正确行为。一旦重置，参考轨迹就不再是那个线性系统，训练目标与 MPC 模型脱钩。
- 参考状态只在环境 reset 时对齐到实测值。
- 参考状态的更新必须发生在奖励计算之前。
- body pitch 的 ωₙ 必须严格小于 body height 的 ωₙ。

### 设计依据

- **二阶而非一阶**：一阶模型在命令阶跃时刻要求无穷大加速度，策略在该步必然被罚且无法消除，形成常数负底噪。二阶模型初始加速度为 0，全程物理可实现。
- **速率饱和而非增益调度**：饱和让小命令保持全带宽、大命令自动退化为匀速斜坡，同时保持"线性系统 + 箱式约束"结构，MPC 侧仍是 QP。变增益会让系统矩阵状态相关，被迫走 SQP。
- **临界阻尼**：超调需要额外的减速控制权限，而这部分权限在低摩擦、重载 domain 下最先耗尽，所以超调量是跨 domain 最不一致的量之一。指定 ζ=1 主动避开最难保持一致的行为。
- **pitch 慢于 height**：height 变化靠四腿对称蹬伸，pitch 变化要求前后腿差动出力，在 trot 对角支撑构型下控制权限更受限。

### 验收

- 数值测试：0.4 rad 的 pitch 阶跃、ωₙ=5、ζ=1，参考轨迹应与解析解 `0.4[1−(1+ωₙt)e^{−ωₙt}]` 在 1e-4 内一致。对照点：t=0.1→0.036，t=0.2→0.106，t=0.4→0.238，t=0.8→0.363。
- 0.6 rad 阶跃时峰值角速度被限幅在 0.8 rad/s（未限幅时应为 `Aωₙ/e = 1.10`）。
- 命令重采样处参考状态连续、无跳变。

## R3 — 相位条件残差估计与零延迟去趋势

### 需求

在线估计**步态相位条件下的基座振荡** `δ̂(φ)`，用途有二：

1. 给 R4 的奖励提供**零延迟**的低频分量提取。
2. 作为 R4 相位条件方差惩罚的目标值。

估计量按 `(速度分桶, 相位分桶, 通道)` 组织，速度分 4 桶、相位分 16 桶量级，用慢速滑动更新（时间常数远长于步态周期）。

### 不变量

- **估计量必须 per-environment**，不得跨 env 共享。不同 env 的 domain 不同，δ 本来就不一样。跨 env 的一致性由 R5 负责，不是这里。
- **必须按速度分桶**。δ 的幅值与形状随行进速度显著变化，不分桶等于强迫所有速度下振荡形状相同，物理上做不到，会退化成常数负奖励底噪。
- **估计量的更新路径与使用路径必须分离**，避免循环依赖：更新时用一个有滞后的低通去趋势（滞后只影响统计量收敛速度，无所谓）；奖励中使用时用相位查表去趋势（因为相位由 gait frequency 积分而来、精确已知，这是零延迟的）。
- 依赖此估计量的奖励项在训练早期不得启用（见 R8 课程），需等待估计量收敛。

### 设计依据

滑动平均或 EMA 有半个步态周期的相位滞后，直接用于瞬态跟踪奖励会严重扭曲误差信号。相位查表利用了 WTW 的一个关键优势：**相位是被命令的、开环已知的时钟**，不需要从接触估计。

### 验收

固定命令跑 30 s，`δ̂` 对相位的曲线应呈现清晰周期波形（1–2 次谐波为主）；阶跃瞬态处，相位查表去趋势的结果不应有滞后，低通去趋势的结果应有可见滞后。

## R4 — 奖励设计

四项改动。所有涉及跟踪误差的项，**测量量都必须先做 R3 的零延迟去趋势**。

### R4.1 参考跟踪（核心项）

对去趋势后的实测值与参考状态之间的误差施加指数型奖励。

**这一项是整个方法的核心机制**：它不罚终点，罚每一步的位置。给 0.4 rad 阶跃时，t=0.1 s 那一步要求的是 0.036 rad 而非 0.4，因此**跑得太快同样被重罚**。一个 0.2 s 到位的激进策略在 t=0.1 时误差 0.214，奖励从 1.00 掉到 0.01 量级，且这个惩罚持续约 0.5 s。这就是"放弃峰值性能换取跨 domain 一致性"的具体代价。

**误差尺度 σ 必须标定，不得拍脑袋**。标定方法：构造参考轨迹与"ωₙ 加倍"的两条候选轨迹，调 σ 使二者在瞬态窗口上的积分奖励差达到最大可能差值的 30–50%。每通道独立标定，量纲不同不可共用。（pitch 通道范围 ±0.4 rad 时标出来约在 0.08–0.12。）

**软目标机制**：检测到大扰动或严重打滑时，该环境的本项在约 0.5 s 内失效。这是设计文档中"response consistency 是软目标，受极端扰动时优先恢复稳定"的具体落地，必须实现。

### R4.2 相位条件方差惩罚

惩罚实测振荡与 R3 估计量之间的偏差。

**语义必须准确**：

> 惩罚的是围绕相位条件均值的**方差**，不是振荡幅值本身。

为什么这个区分是本质的。两个策略的 z 振荡峰峰值都是 2 cm：

- 策略 A：每周期波形几乎一致、相位锁定 → MPC 可前馈预测，arm 反向抵消，**EE jitter ≈ 0**
- 策略 B：幅值相同但每周期波形不同、相位漂移 → MPC 无法预测，**2 cm 全部泄漏到 EE**

传统幅值惩罚对 A 和 B 一视同仁。本项的目标是把 B 变成 A，而不是把幅值压到 0——压幅值要消耗额外腿部力矩，伤鲁棒性与能效。副作用上本项会顺带轻微压幅值，但不硬压：策略可自由选择"振荡小"或"振荡大但规整"，两条路 MPC 都能接受。

命令阶跃后约 `2/ωₙ` 内本项不计，那段由 R4.1 负责。

### R4.3 稳态增益锁定

命令稳定足够久后（约 `3/ωₙ`），惩罚去趋势实测值与**命令本身**（不是参考状态）的偏差。

作用是把 MPC 模型的稳态增益强制钉到 1。body height 通道最需要：原版中命令 0.30 m 可能实际走出 0.27 m，挂 3 kg 负载后变 0.25 m。

### R4.4 保留并降权原姿态跟踪项

原有的瞬时姿态跟踪项权重降到原来的 10–20%，**不要删除**。它守住一个真实的失效模式：策略可能在步态周期内做剧烈姿态摆动，从而在"去趋势后的平均意义上"骗过 R4.1。

### 不变量

- 若总奖励是 `r_task · exp(k·Σr_aux)` 的乘性结构，R4.1 作为 task 项，R4.2/4.3/4.4 作为 aux 因子。不得把一致性项写成加性，否则量纲难调且早期训练会淹掉 task reward。
- 所有新增超参进配置，不得硬编码。

### 验收

- 构造三条人工轨迹（跟随参考 / 2× 激进 / 0.5× 迟钝），R4.1 的积分奖励排序必须是 跟随 > 迟钝 > 激进，且激进者的瞬态段奖励接近 0。
- 关闭去趋势重跑，R4.1 的奖励方差应显著变大（证明去趋势必要性）。
- 训练 1000 iter，四项奖励曲线无 NaN、无发散。

## R5 — 跨域一致性（Nominal Twin）

### 需求

显式惩罚"同一命令在不同 domain 下响应不同"。这是 Contribution 1 的直接实现。

把环境分组（组大小 4 量级）。**组内共享**：命令序列、相位时钟、重采样时刻。**组内随机化**：摩擦、质量、负载、地形、电机强度、arm 构型。

每组指定一个**标称孪生**环境（平地、标称质量、无负载、arm 固定、无扰动），组内其余环境的去趋势响应向孪生环境对齐（孪生一侧不回传梯度）。

### 不变量

- **必须用 nominal twin，不得用组内均值方差**。组内均值方差存在退化解：策略可以通过"在所有 domain 下同样迟钝"把方差降到 0，一致性和带宽同时塌掉。Twin 方案把"一致"的语义变成"在困难 domain 下表现得像在标称 domain 下一样"，自带性能锚点。
- 组内相位时钟必须同步。相位错开后跨域对比无意义。
- **必须处理终止不对称**：某个环境摔倒被 reset 后，与组内其他环境的相位和命令时序全部错开。此时该组的一致性项必须失效，直到组内重新同步（下一次重采样）为止。孪生环境自身摔倒时整组失效，因为对齐目标消失。
- 所有参与比较的量必须是 body frame 的速度/角速度，以及**相对局部地形**的高度。崎岖地形上绝对世界系高度跨环境不可比。

### 附带收益（值得在论文里点明）

标称孪生环境的响应**就是** Contribution 2 要辨识的 nominal low-order response，训练目标与辨识目标在定义上闭合。孪生环境的摔倒率还可以直接当作训练健康度监控。

### 验收

同组环境的命令向量逐维相同、相位同步；人为让一个环境摔倒，一致性项按预期失效并在下次重采样恢复；孪生环境的 domain 参数确认为标称值。

## R6 — 富激励命令信号

### 需求

分配约 25% 的环境跑辨识模式，使用富激励命令：

| 信号  | 特征                          | 用途                           |
| ----- | ----------------------------- | ------------------------------ |
| PRBS  | 随机方波，切换间隔 0.5–3.0 s | 覆盖阶跃瞬态，对应 ωₙ、ζ    |
| Chirp | 正弦扫频 0.1 → 2.0 Hz        | 标定闭环带宽，可直接画 Bode 图 |
| Ramp  | 不同斜率斜坡                  | 验证速率饱和位置               |

姿态通道（body height、body pitch）尤其需要，原版中它们几乎没有瞬态激励。

### 不变量

- **辨识环境必须排除在自适应课程之外**。否则课程会因这些环境奖励偏低而误判，把命令范围一路收窄。
- **课程的进度判据只使用原版的跟踪类奖励**，不得把 R4.1/R4.2/R5 等一致性相关奖励算入。否则课程会卡死在低难度区域。

### 设计依据

WTW 默认重采样周期在 10 s 量级，一个 episode 内命令只跳变几次，瞬态样本严重不足。参考模型将形同虚设，R8 的标定与后续辨识也没有数据支撑。

### 验收

辨识环境单 episode 内命令跳变 ≥ 20 次；chirp 环境的命令频谱覆盖 0.1–2.0 Hz；课程推进速度与原版相当。

## R7 — 观测与适应能力

### R7.1 观测需要新增的信息

- **参考状态本身，以及参考状态与命令的差**。只给命令的话，策略不知道"此刻应该走到哪一步"，必须自己在内部反推参考轨迹，跟踪难度大幅上升。原始命令保留。
- **arm 关节位置/速度、EE 相对 base 的位置**。不给的话策略只能被动抗扰，跨 arm-configuration 的一致性上限会很低。

### R7.2 显式适应通路（必需，非可选）

需要论证并实现的机理：

> 要在不同摩擦/质量/负载/arm 构型下对同一命令给出**相同**响应，策略必须隐式辨识当前 domain 并做补偿。响应一致性与在线系统辨识在数学上是同一件事的两面。

因此必须有显式的 domain adaptation 通路，不能只靠观测历史的隐式记忆。教师用特权信息（摩擦、质量、负载质量与质心偏置、电机强度、arm 惯量投影）编码为低维隐变量，学生用约 0.5–1.0 s 的本体感知历史回归它。

**隐变量上加辅助监督**：从隐变量直接预测"当前 domain 下的名义响应参数偏移"（如各通道的等效 ωₙ 与 DC gain 偏差）。这让隐变量的语义与一致性目标对齐。

若代码库已有 adaptation 模块，复用并加上辅助监督头即可。

### 验收

观测维度变化被记录，旧 checkpoint 加载时明确报错而非静默错位；学生的隐变量回归误差随训练下降；辅助头预测与真实 domain 参数的相关系数 > 0.6。

## R8 — 课程与参数标定

### R8.1 四阶段课程

| 阶段 | 内容         | 启用项                                                                      | 退出判据                      |
| ---- | ------------ | --------------------------------------------------------------------------- | ----------------------------- |
| 1    | 纯鲁棒性     | 原版奖励、固定 trot、弱随机化；R3 估计量开始更新但不用于奖励                | 跟踪奖励收敛，平地稳定        |
| 2    | 接入参考模型 | R4.1（权重从 0 线性升起），随机化仍弱                                       | R4.1 奖励 > 0.8               |
| 3    | 接入一致性   | R4.2 + R4.3 + R5（权重慢升，建议 1000 iter ramp），随机化拉满，arm 扰动开启 | 一致性指标达标                |
| 4    | 鲁棒性回补   | 加大推力扰动与地形难度，权重保持不变                                        | 鲁棒性指标恢复到阶段 1 的 90% |

**阶段 3 最容易崩**，权重必须慢升。

**阶段 3 结束与阶段 4 结束各存一个 checkpoint**，二者是"鲁棒性–可预测性帕累托前沿"上的两个点。用 4–6 组不同权重训出整条前沿，这是 Contribution 1 的主图之一。阶段 4 的存在本身就是"一致性是软目标"这一声明的实证，必须保留并报告。

### R8.2 参考模型参数标定（阶段 1 结束后执行）

用阶段 1 的纯鲁棒 checkpoint，在**全随机化范围**下发阶跃命令，测量实际可持续达到的加速度/速率，反推参数。

**必须遵守的两条**：

1. **取 20 分位数**，不是均值，更不是最大值。参考模型若在困难 domain 下不可实现，策略只能在"追不上参考"和"为了追上而失稳"之间二选一——这是鲁棒性损失的主要来源。留有余量的参考模型让一致性奖励在困难 domain 下仍然可达，不需要零和取舍。这一步的存在本身也回答了审稿人"你怎么保证不牺牲鲁棒性"。
2. **姿态通道必须按 `(domain, 阶跃发生时刻的相位)` 联合分桶统计**，速度通道按 domain 分桶即可。这是姿态通道与速度通道的本质差异：姿态改变靠支撑腿蹬伸，控制权限随步态相位周期性变化，trot 双支撑切换瞬间 pitch/roll 力矩显著下降。只按 domain 取分位数会得到一个"平均相位可实现、不利相位不可实现"的参考模型。

**诊断信号**：标定错误时，训练奖励曲线会出现**与步频同频的周期性波动**。观察到此现象立即回头重新标定。

标定流程需可复现、结果输出为配置文件。

### R8.3 域随机化分层

范围必须明确、可分层、可复现，因为它同时是实验自变量：

| 档位            | 定义                       | 用途                               |
| --------------- | -------------------------- | ---------------------------------- |
| In-distribution | 训练采样范围               | 主要指标                           |
| Held-out        | 训练范围内但未采样到的组合 | 验证泛化而非记忆                   |
| OOD             | 超出训练范围               | 展示一致性优雅退化、鲁棒性优先接管 |

三档定义写成独立配置，评测直接读取。

### 验收

四个阶段 checkpoint 齐全；标定流程可复现；训练曲线无步频同频波动；阶段 4 结束时鲁棒性指标 ≥ 阶段 1 的 90%。

## R9 — 评测与数据导出

### R9.1 评测

对固定的一组测试命令（阶跃、斜坡、正弦、多通道复合），在三档 domain 下各跑 N=20 次。

**速度通道与姿态通道必须分开报告**——物理瓶颈不同，混在一起会稀释结论。

需要产出的指标：

1. settling time / overshoot 的跨域标准差
2. 相位条件响应离散度 `E_φ[Var_domain(y | φ)]`
3. 残差傅里叶系数的跨域方差（n = 1, 2, 3）
4. **低阶模型拟合优度**：一阶 / 二阶 / 二阶+残差 三种模型的 R² 与归一化残差能量，随模型阶数的曲线
5. **鲁棒性未退化的证明**：崎岖地形通过率、推力恢复成功率、最大可跟踪速度，对比原版 WTW
6. 姿态通道专属：
   - 阶跃响应族图（同一阶跃，三档 domain 各 20 条曲线叠画，与原版 WTW 并排）
   - 按**起始相位分组**的响应离散度
   - **闭环 Bode 图**（用 chirp 数据），跨 domain 画成带状
   - DC gain 随负载的漂移
   - roll 通道 `δ(φ)` 幅值与 roll 命令范围之比（支撑"v1 冻结 roll"的设计决策）

**核心断言**：指标 4 与指标 5 画在同一张图的两轴上，即为 Contribution 1 的主图——

> response-consistent policy 能被**明显更简单**的模型描述到同等精度，且鲁棒性未退化。

姿态部分的主图建议用 Bode 图。经典控制的表示对做 MPC 的读者最有说服力，且一张图同时说明两件事：策略被塑造成了带宽明确的低阶系统，且该系统跨 domain 几乎不变。

### R9.2 辨识数据导出

供 Contribution 2 使用的时序数据，需包含：命令、参考状态、实测 base SE(3) 与 twist、步态相位、gait frequency、arm 状态、domain 特权参数（仅仿真）、地形标签。格式自选，但需自带元数据说明采样率与坐标系约定。


## 明确不做的事

- 闭环辨识、feasibility envelope、MPC 求解器（后续文档）
- gait switching、contact schedule optimization
- 显式 arm reaction wrench 建模
- vision
- **不要把通道耦合塞进参考模型**。保持各通道解耦是它的全部价值。耦合交给 feasibility envelope 处理：参考模型回答"给定命令，响应长什么样"，可行域回答"这条命令组合现在允不允许发"。
- **不要把 body pitch / body height 改成速率命令**。pitch/roll 有绝对锚点（重力方向由 IMU 直接观测、无漂移），height 相对地形可观测，因此角度/位置命令是正确的。速率命令会引入策略内部积分器（MPC 看不见的隐状态）、稳态时命令恒为 0（信息量为零、必须靠记忆维持姿态）、且稳态增益奖励无从定义。MPC 侧若需要速率约束，把决策变量取为角度增量并加箱式约束即可，策略接口不变、求解结构仍是 QP。

## 已知风险与诊断信号

| 现象                                   | 可能原因                                                       |
| -------------------------------------- | -------------------------------------------------------------- |
| 奖励曲线出现与步频同频的波动           | 姿态通道标定未按相位分桶                                       |
| 一致性奖励是常数负底噪、不下降         | 相位残差估计量未按速度分桶；或参考模型在多数 domain 下不可实现 |
| 阶段 3 训练崩溃                        | 一致性权重升得太快；或 20 分位数取成了均值                     |
| 跟踪奖励信噪比极差（尤其 pitch）       | 忘记去趋势。trot 固有振荡 ±2–3° 与参考轨迹量级可比          |
| 命令范围被课程一路收窄                 | 辨识环境未排除出课程；或课程判据混入了一致性奖励               |
| 一致性项表现为噪声                     | 组内相位未同步；或终止不对称未处理                             |
| 策略跨 domain 一致但整体迟钝、带宽塌陷 | 误用了组内均值方差而非 nominal twin                            |
| 激进策略与参考策略得分接近             | σ 太大，缺乏区分度；重新标定                                  |
