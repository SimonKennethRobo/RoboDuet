# RL–MPC 论文 insight、假设修订与验证重点

整理日期：2026-09-12。依据此前讨论及截至 2026-09-11 已归档的本地实验。本文用于收敛论文主张和后续研究范围；其中提出的假设与验证安排尚不代表已完成结果，远端训练状态未在本次整理中刷新。

论文应围绕**持续行走中的世界坐标系末端 SE(3) 轨迹跟踪**展开。最近的 hold_push 与 reach 实验主要用于暴露命令接口、伺服响应和预测模型的问题。它们是研究过程中的诊断工具，不能替代原任务，也不应以两个场景的分数决定方法结构。原任务与方法动机见[项目设计](project-design-rlmpc-v3.md)。

**核心 insight：训练低层控制器时，应考虑它是否便于上层预测和协调。** Locomotion 的平均跟踪精度与稳定性，不能充分描述一个 policy 对预测式 manipulation 的价值。两个 policy 即使平均速度误差接近，其瞬态延迟、步态波动以及不同负载下的响应重复性也可能不同，进而影响上层能否提前安排机械臂运动。

建议将论文的核心研究命题表述为：

> 在保持有效运动能力和鲁棒性的前提下，主动塑造底盘闭环响应，使固定复杂度的模型在规划所需时域内更准确，并检验这种可预测性是否改善持续行走中的末端控制。

对应的研究链条是：

```text
响应塑造
  → 相同模型结构与数据预算下，留出多步预测更准确
  → 在相当的实际行走表现下，末端预测协调更有效
```

每个箭头都需要独立证据。RL locomotion 与 model-based manipulation 的组合已有研究先例，因此本文的贡献应落在响应塑造及其对预测协调的作用机制上。相关背景见 [Ma 等，2022](https://arxiv.org/abs/2201.03871)。

**“可预测”需要同时满足任务能力和适用范围要求。** 几乎不响应命令的 policy 也可能容易预测；一个高度重复但幅度过大、频率过高的底盘运动，也可能超出机械臂补偿能力。因此需要同时观察响应误差、有效命令增益、实际行走速度、姿态调节能力和扰动恢复表现。不能通过降低运动能力获得表面上的一致性优势。

可预测性应限定在明确的命令范围、步态、运行条件和预测时域内。正常行走阶段的响应重复性与强扰动下的恢复能力需要分别分析，恢复区间仍计入完整任务评价。相同命令不意味着不同初始状态或恢复阶段应产生相同瞬时输出；跨条件比较需要控制或说明初始状态、相位和可用历史。

**末端相关的预测误差比单个综合 RMSE 更接近论文问题。** 保留解析运动学关系：

```text
T_WE = T_WB · T_BE(q)
```

底盘不同方向的误差会通过机械臂姿态和力臂，以不同程度影响末端位置与姿态。综合响应误差下降，不保证关键方向误差下降；预测改善也不自动创造额外的工作空间或执行器带宽。这里需要用运动学和共同条件下的预测、执行记录检验误差传播，无须因此增加一个端到端末端辨识器。这是解释与验证方向，尚不能据此判定当前持姿退化的根因。

**已有证据支持闭环响应建模的价值，但尚未闭合响应训练的因果链。** 目前的主要发现及其写作边界如下。

| 发现与证据 | 目前能够支持的判断 | 仍不能据此声称 |
| --- | --- | --- |
| 多个 policy 的底盘留出预测中，一阶模型在多个通道优于瞬时响应假设；普通 robust policy 也有建模收益 | 高层需要考虑 policy 闭环响应；低阶建模值得验证 | response-consistent training 是获得收益的必要条件，或所有通道均改善 |
| 现有 robust 与 RL-MPC runs 的观测、历史长度和训练配置不同 | 可作为候选筛选与探索性对比 | 组间差异由一致性奖励单独造成 |
| 原机械臂目标更新与理想速度预测存在接口失配，后续已改为持续积分目标并核对执行端目标 | 执行接口是模型假设的一部分，必须一致 | 目标回读一致就等于实际关节运动理想，或原持姿问题已完成因果归因 |
| 新机械臂模型在独立确认数据的 300–500 ms 预测改善，但 1 s 预测恶化；reach 改善、hold_push 退化 | 模型收益依赖预测时域与闭环访问分布，需要检验收益如何传递 | 辨识模型普遍优于理想臂模型，或某一个误差源已被证明导致退化 |
| 显式耦合项没有稳定的独立增量预测收益 | 当前证据不足以启用更复杂耦合结构作为必要模块 | 底盘与手臂之间不存在物理耦合 |
| 底盘辨识主要验证五通道响应，新 OCS2 试验在预测窗口内固定实测 roll | 已验证部分响应通道和有限任务的闭环执行 | 已实证完整步态相关 SE(3) 预测，或六自由度均可独立控制 |
| 当前闭环使用共同经验限幅，未验证辨识得到的动态 feasibility envelope | 可以说明使用的运行范围与约束形式 | 已识别物理安全域、具有硬安全保证或完整物理可行性 |

底盘结果见[留出响应预测报告](../data/identification/balanced_validation/prediction/report.md)；配置差异见[policy benchmark 说明](../benchmark/results/rlmpc_p0_corrected/comparison.md)；机械臂与 OCS2 结果见[完整实验记录](rlmpc-arm-servo-ocs2-20260911.md)。

需要特别区分最近 OCS2 对照的含义：三组均使用同一个 policy 和相同的辨识底盘，主要改变机械臂预测模型。`base_only` 表示“辨识底盘 + 理想臂速度”，并非理想底盘基线。这些试验没有改变 response training，不能回答其训练贡献，也不能代替底盘建模消融。

作为诊断证据，分别辨识使该批 reach 的位置 RMSE 从约 11.17 cm 降至 7.59 cm，同时使 hold_push 从约 0.30 cm 升至 1.31 cm。当前结论是收益存在任务依赖；这些数值不应成为持续移动论文的主结果。旧 SLSQP 与新 OCS2 实验的接口、运动学和优化实现也不同，不宜把跨协议差异归因于单一修改。

**论文假设建议收紧为三条可检验命题。**

1. **H1：响应塑造。** 在预先规定的正常行走范围内，响应训练能在保持有效跟踪和鲁棒性的条件下，减少给定命令、相位及初始条件下的宏观响应不确定性。需要同时验证有效命令增益、运动表现与恢复能力。若一致性收益主要来自响应变弱或运动能力下降，该假设不成立。
2. **H2：同等复杂度下的可预测性。** 对匹配训练条件下的 policy，使用相同模型结构、数据预算和拟合流程，响应塑造能够降低完整留出轨迹上的多步自由预测误差。评价时域覆盖 MPC 实际使用范围；模型参数分别拟合。若优势只出现在单步拟合、已见轨迹，或依赖更复杂模型，就不能支持此假设。
3. **H3：预测改善向任务收益的传递。** 在共同执行接口、机械臂模型、约束和控制设置下，预测改善能在相当的实际行走表现下转化为持续移动中的 EE 跟踪收益。若收益主要来自减速、停步、单独调权或改变动作范围，不能归因于预测协调；若预测确有改善但任务没有收益，应报告其适用边界。

这三条假设不要求所有工况下使用一个完全一致的响应，也不预设一阶模型、步态残差或显式耦合必然有效。训练参考用于塑造行为，辨识模型用于预测最终行为，二者不必同阶，但其近似误差必须通过验证。

**验证优先级首先应回到训练贡献。** 已有 [E4 消融方案](rlmpc-e4-response-ablation-20260911.md)比较 `reference_only`、`within_domain` 和 `full_consistency`，可以检验额外一致性项相对 reference shaping 的增量价值。所有组保留 reference tracking，因此这组实验不能单独证明整个响应塑造方案相对普通 robust training 的收益。

评估这些实验时，应核对实际 checkpoint 配置、奖励激活情况、有效配对覆盖率和组间失同步，避免把未生效的训练项解释成算法失败或成功。单个训练 seed 只适合机制筛查，多次评测不能替代独立训练重复。本文未刷新 E4 完成状态。

完整训练主张还需要匹配架构、观测、随机化、命令分布、训练预算和种子的普通 policy 对照。关闭响应塑造时，应恢复完整的普通跟踪任务，尤其不能保留原姿态奖励的退场安排却移除接替它的 reference reward。

**随后用一个持续移动任务检验预测协调。** 优先选择沿墙扫描或长距离世界系 EE 轨迹跟踪，提前确定速度、负载条件、评价协议和一套控制设置。参考轨迹应覆盖持续行走过程，并记录实际位移、速度和停步比例，防止仅凭末端误差判断移动操作效果。推扰用于检查恢复能力，reach 用于接口回归，均不替代主任务。

核心交叉对照如下：

|  | 理想底盘响应 MPC | 各自辨识的同类底盘响应模型 MPC |
| --- | --- | --- |
| 匹配配置的普通 policy | A：共同基线 | B：检验普通 policy 上的建模收益 |
| 响应塑造 policy | C：检验理想模型下的训练收益 | D：检验响应塑造与预测协调的组合收益 |

四组共用机械臂执行接口、机械臂模型、约束、代价权重和求解设置。两种 policy 分别用相同预算辨识底盘参数，并使用共同的验证与模型选择规则。B−A 与 D−C 描述各 policy 上的建模作用，C−A 与 D−B 描述各模型设置下的训练作用；D 排名最好本身不能证明存在额外的交互收益。

数据划分按完整轨迹和条件进行。开发期查看过的测试数据应视为已使用数据，最终确认需要新的留出条件；相邻采样点随机拆分不能支撑泛化主张。先冻结模型结构、控制设置和评价指标，再开展确认实验，避免根据主测试场景反复调节。

主结果需要同时包含 EE 位置与姿态误差、统一定义的步态相关抖动、实际行走表现，以及完整任务中的失败和恢复情况。预测分析报告实际规划时域内的底盘位姿误差及关键方向误差。只有完成对应验证后，才能将完整 SE(3) 预测、步态抑振或真机世界系精度写成实证结论。

**系统辨识应设置有限终点，服务上述验证。** 当前应优先处理会破坏公平比较的命令语义、时间对齐、静态偏差和动作覆盖问题。机械臂只需选定一个经过共同工作范围与预测时域验证的公共模型，冻结后用于各组对照。已知执行失配仍需修复，但验收依据应是独立数据上的接口与预测有效性，不能改成“让 hold_push 和 reach 都优于基线”。

如果共同伺服模型仍有明显稳态漂移或预测失真，先做有限的静态与多步校准；显式耦合只在独立残差分析和留出预测证据支持时加入。辨识边界保持为“命令接口 + RL policy + 伺服 + 机器人”，MPC 本身不折叠进被辨识对象，正运动学保持解析计算。

**论文贡献建议集中为响应塑造和预测协调，其他模块按证据决定写作位置。**

| 内容 | 建议定位与修改 |
| --- | --- |
| Response shaping | 主要方法贡献；其对有效响应、可预测性和鲁棒性的影响由匹配消融支持 |
| Policy-aware MPC | 主要协调方法；明确优化 locomotion commands，并通过闭环模型预测底盘运动 |
| 系统辨识 | 连接训练与规划的必要方法；重点交代边界、模型预算和留出验证，不追求模型复杂度本身 |
| Gait-phase residual | 有独立增量预测和任务收益时作为重点；否则简化或移除相应贡献主张 |
| Feasibility envelope | 当前按经验运行范围或正则项描述；有独立标定与执行证据后再提升主张，不表述为安全保证 |
| 机械臂伺服辨识与显式耦合 | 伺服校准作为执行条件；复杂耦合暂不扩展为独立创新点 |
| hold_push / reach | 保留为诊断与回归记录，必要时进入附录；不作为持续移动任务的替代证据 |

Introduction 应突出“为什么低层响应需要为预测协调而塑造”；Methods 应说明 H1–H3 对应的训练、模型和控制接口；Experiments 按响应变化、留出预测、持续移动任务的顺序组织。理论结构、实际实现与已验证范围应分别说明，避免以模型中包含某个状态或模块替代对应实证。

结论应随证据调整：若额外一致性项没有增益而 reference shaping 有增益，就收敛到 reference shaping 的贡献；若普通 policy 的辨识已达到相近效果，就缩小响应训练的主张；若预测改善尚未转化为持续移动收益，就不能宣称完整方法已有效。无需通过继续优化诊断场景来维护预设结论。

可用于后续英文摘要或 Introduction 的研究定位草案：

> We investigate whether shaping the closed-loop response of a locomotion policy improves its suitability for predictive manipulation. Under matched model complexity and identification budgets, we test whether response shaping improves finite-horizon prediction while preserving useful motion and robustness, and whether these gains translate into end-effector tracking during sustained walking.

该段使用研究问题与验证表述；只有相应实验完成后，才改写为结果性陈述。
